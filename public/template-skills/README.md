# Asterloom template skills

Version 1.1.0. 75 bundled template guides generated by scripts/build-template-skills.ts. Edit the compiled authored template data, then run npm run template-skills. npm run template-skills -- --check detects drift.

Creation uses compact source-selection guidance, then only the selected full template skill. These complete reference files are bundled for inspection and reuse; they are not all sent to every AI request. All 75 recipes have native Godot factory controls and AI writer contracts. Their source requirements and additional capability protocols still apply. The earlier three pilot presentations retain separate guides under native/. Native automated checks do not establish human learning quality or universal smaller-model reliability.
